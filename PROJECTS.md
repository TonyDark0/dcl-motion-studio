# Project boundaries

This Git distribution is **Project 1: Local Studio**. It includes the editor, local Fastify API, native constraints patch, local model setup, SQLite projects and local GLB export. Open the editor at `/` or `/app`; `/docs` is the local user guide.

**Project 2: Hosted beta** is maintained separately. Its marketing landing, GSAP, Docker/Runpod worker, Vercel gateway, Redis/R2, cloud adapters, analytics, quotas and feedback dataset are excluded from this repository. Changing this copy does not redeploy or alter that project.

Models are external dependencies with independent terms; local operation does not make their weights Apache-2.0. See docs/LICENSING.md.
