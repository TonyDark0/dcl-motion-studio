# Creator Hub integration proposal

**Status: not implemented.** The local application is an independent project. It has no official Creator Hub inclusion, adapter, bundled installer or upstream contribution in this source distribution.

[Decentraland Creator Hub](https://github.com/decentraland/creator-hub) is a potential future distribution/integration point. Any proposal would need to establish maintainer expectations, process isolation, model setup, update behavior and the licenses of dependencies/resources.

The editor, local inference API and saved project format remain usable independently of that decision. See [project boundaries](../PROJECTS.md) and [installation](../README.md#local-installation).
