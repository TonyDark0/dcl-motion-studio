# Example recordings

These MP4 files record the existing DCL Motion Studio landing page served locally, using its default avatar and previously prepared examples. They are documentation media, not a deployment of the landing or an installation dependency.

- `text-to-emote.mp4`: the text example and displayed prompt, with the avatar playing its existing animation.
- `video-comparison-1.mp4`, `video-comparison-2.mp4`, `video-comparison-3.mp4`: the three reference videos alongside tracking and existing Fast/Pro results.
- GIFs provide animated previews in the GitHub README; JPEGs are still previews for the additional comparisons.

Recorded at 1280×900, without audio, from the existing browser playback. Each excerpt lasts approximately six seconds. The captures do not run new inference, alter motion, replace tracking or hide a failed generation. Playback recordings are not performance measurements. Landing examples may include creator adjustments; they do not promise the same result for every input.

Reference videos and depicted assets retain their applicable rights; the application's Apache-2.0 license does not relicense third-party reference footage. These recordings are not training data or permission to train on the depicted material.
